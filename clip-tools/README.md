# Інструменти для кліпу «Самотній привид»

Два скрипти, які автоматизують виробництво кліпу за розкадровкою
(`../storyboard-lonely-ghost.md`): генерацію кадрів і збирання відео.
DaVinci Resolve стає непотрібним — але інструкція з ручного монтажу
в розкадровці лишається як альтернатива.

## Що потрібно

- **Python 3** (без сторонніх бібліотек).
- **Stable Diffusion webui** (Automatic1111, Forge або SD.Next) із моделлю
  DreamShaper XL — для генерації кадрів. На RTX 2060 (6 ГБ) запускай webui
  з прапорцем `--medvram` (Forge впорається і без нього).
- **ffmpeg** у PATH — для збирання відео.
- Трек «Самотній привид» із Suno (mp3/wav).

## Крок 1. Згенерувати кадри

Запусти webui з прапорцем `--api`, вибери в ньому DreamShaper XL, потім:

```bash
python generate_frames.py --variants 4
```

Скрипт прожене всі 21 кадр із `frames.json` (промпт кадру + спільний базовий
стиль + negative prompt) і складе варіанти в `variants/` як
`kadr_01_v1.png` … `kadr_21_v4.png`. Перерваний запуск можна просто
повторити — готові файли пропускаються.

Корисне:

- `--only 3,5,9` — перегенерувати лише вказані кадри;
- `--variants 6` — більше варіантів на відбір;
- `--url http://127.0.0.1:7860` — якщо webui на іншому порту.

Порада з розкадровки діє і тут: спершу відбери вдалий образ привида на
кадрах із героєм (3, 5, 6, 9…), а вже потім генеруй пейзажі.

## Крок 2. Відібрати варіанти

Переглянь `variants/`, вибери по одному найкращому варіанту на кожен кадр
і скопіюй його в папку `frames/` під іменем без суфікса варіанта:

```
frames/kadr_01.png
frames/kadr_02.png
...
frames/kadr_21.png
```

## Крок 3. Зібрати кліп

```bash
python make_video.py --audio track.mp3
```

Скрипт сам:

- розставить кадри по таймінгах розкадровки (3:46);
- додасть кожному кадру рух Ken Burns — зум або панораму, як у розкадровці;
- зробить cross dissolve між кадрами (0.8 c, налаштовується `--transition`);
- накладе єдиний грейд: легкий teal у тінях, контраст, віньєтка, зерно
  (вимикається `--no-grade`);
- зробить fade to black наприкінці й підкладе трек із плавним затуханням.

На виході — `lonely_ghost.mp4`, 1920×1080, 30 fps. Якщо хочеться жорсткіших
катів у такт на приспівах — зменш `--transition` до 0.2–0.3 або змонтуй
фінальну версію в Resolve, використавши цей рендер як чернетку.

## Таймінги та промпти

Все в одному файлі — `frames.json`: промпти, межі секцій у секундах і тип
руху для кожного кадру (`zoom_in`, `zoom_out`, `pan_left`, `pan_right`,
`pan_down`, `pan_up`). Хочеш змінити тайминг під фінальну структуру треку
в Suno чи поміняти рух кадру — редагуй JSON, скрипти підхоплять.
