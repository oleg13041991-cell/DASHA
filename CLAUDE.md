# CLAUDE.md — правила проекта Rags to Riches

## Проект
Android idle arcade simulator на Unity 6 (URP, low-poly 3D), C#. Референс механик: Pizza Ready. Тема: путь от нищего до магната, 6 ступеней-локаций с престижем.

Полный план разработки: `docs/PLAN.md`. Текущая стадия и её DoD: `docs/STAGE0.md`.

## Архитектура
- Симуляция (экономика, очереди, таймеры, престиж, оффлайн-расчёт) — чистый C# в Assets/Scripts/Core, без UnityEngine. Покрыта unit-тестами.
- MonoBehaviour — тонкий View-слой (Assets/Scripts/View): анимации, NavMesh, ввод, камера.
- Весь баланс — JSON в StreamingAssets (цены, таймеры, кривые, цели ступеней). Магические числа запрещены.
- Ступень (Stage) — data-driven: конфиг описывает зоны, ресурсы, посты, цели. Новая ступень = новый JSON + префабы, без изменения Core.
- Time.time в Core запрещён — только инжектируемый ITimeProvider (тесты + оффлайн-расчёт).
- Событийная шина между Core и View.

## Правила работы
- Стадия плана = ветка, merge только при зелёных тестах (Unity Test Runner, edit mode).
- Перед завершением задачи: git status, реальный коммит (ground-truth верификация).
- Object pooling обязателен: NPC, машины, деньги, партиклы.
- Сейвы: атомарная запись (temp + rename), версионирование схемы, бэкап-слот.
- Никаких TODO-заглушек в мержах.

## Стиль
- C# conventions Microsoft, nullable enabled.
- PascalCase публичное, _camelCase приватные поля.
- Один класс — один файл — одна ответственность.

## Ограничение среды Claude Code
Claude Code работает в облачном контейнере без Unity Editor и Android SDK:
он пишет код, конфиги, editor-скрипты и тесты, но открывать проект,
запускать Unity Test Runner и собирать APK нужно локально на машине
разработчика. Editor-скрипты проекта (меню «RagsToRiches») автоматизируют
настройку URP, сборку сцены и APK одной кнопкой.
После первого открытия проекта в Unity закоммить сгенерированные .meta-файлы.
